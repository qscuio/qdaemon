  # QDaemon - Professional Linux Daemon Framework                                                                                                                                                       
                                                                                                                                                                                                        
  ## Overview                                                                                                                                                                                           
                                                                                                                                                                                                        
  A professional-grade Linux daemon framework in C providing:                                                                                                                                           
  - Thread pool with work stealing                                                                                                                                                                      
  - High-performance event loop (epoll-based)                                                                                                                                                           
  - Custom slab/arena memory allocator                                                                                                                                                                  
  - Unix domain socket IPC for multi-instance communication                                                                                                                                             
  - Netlink-based kernel-userspace IPC                                                                                                                                                                  
  - Client library for building services

  ## Component Specifications                                                                                                                                                                           
                                                                                                                                                                                                        
  ### 1. Memory Allocator (qd_memory)                                                                                                                                                                   
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - Reduce fragmentation through slab allocation                                                                                                                                                        
  - Fast allocation for fixed-size objects                                                                                                                                                              
  - Arena allocator for temporary/batch allocations                                                                                                                                                     
  - Memory pooling per-thread to reduce contention                                                                                                                                                      
                                                                                                                                                                                                        
  **Key Structures:**                                                                                                                                                                                   
  ```c                                                                                                                                                                                                  
  // Slab allocator for fixed-size objects                                                                                                                                                              
  typedef struct qd_slab_cache {                                                                                                                                                                        
  size_t obj_size;                                                                                                                                                                                      
  size_t align;                                                                                                                                                                                         
  struct qd_slab *slabs_full;                                                                                                                                                                           
  struct qd_slab *slabs_partial;                                                                                                                                                                        
  struct qd_slab *slabs_empty;                                                                                                                                                                          
  pthread_mutex_t lock;                                                                                                                                                                                 
  // Per-CPU caches for lock-free fast path                                                                                                                                                             
  struct qd_slab_cpu_cache *cpu_caches;                                                                                                                                                                 
  } qd_slab_cache_t;                                                                                                                                                                                    
                                                                                                                                                                                                        
  // Arena for batch allocations                                                                                                                                                                        
  typedef struct qd_arena {                                                                                                                                                                             
  void *base;                                                                                                                                                                                           
  size_t size;                                                                                                                                                                                          
  size_t offset;                                                                                                                                                                                        
  struct qd_arena *next;                                                                                                                                                                                
  } qd_arena_t;                                                                                                                                                                                         
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  **API:**                                                                                                                                                                                              
  ```c                                                                                                                                                                                                  
  // Slab allocator                                                                                                                                                                                     
  qd_slab_cache_t *qd_slab_cache_create(size_t size, size_t align);                                                                                                                                     
  void *qd_slab_alloc(qd_slab_cache_t *cache);                                                                                                                                                          
  void qd_slab_free(qd_slab_cache_t *cache, void *ptr);                                                                                                                                                 
                                                                                                                                                                                                        
  // Arena allocator                                                                                                                                                                                    
  qd_arena_t *qd_arena_create(size_t initial_size);                                                                                                                                                     
  void *qd_arena_alloc(qd_arena_t *arena, size_t size);                                                                                                                                                 
  void qd_arena_reset(qd_arena_t *arena);                                                                                                                                                               
  void qd_arena_destroy(qd_arena_t *arena);                                                                                                                                                             
                                                                                                                                                                                                        
  // General allocator (routes to appropriate backend)                                                                                                                                                  
  void *qd_malloc(size_t size);                                                                                                                                                                         
  void *qd_calloc(size_t nmemb, size_t size);                                                                                                                                                           
  void *qd_realloc(void *ptr, size_t size);                                                                                                                                                             
  void qd_free(void *ptr);                                                                                                                                                                              
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  ### 2. Thread Pool (qd_threadpool)                                                                                                                                                                    
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - Work-stealing for load balancing                                                                                                                                                                    
  - Lock-free work queues where possible                                                                                                                                                                
  - Priority support for tasks                                                                                                                                                                          
  - Graceful shutdown                                                                                                                                                                                   
                                                                                                                                                                                                        
  **Key Structures:**                                                                                                                                                                                   
  ```c                                                                                                                                                                                                  
  typedef struct qd_task {                                                                                                                                                                              
  void (*func)(void *arg);                                                                                                                                                                              
  void *arg;                                                                                                                                                                                            
  int priority;                                                                                                                                                                                         
  struct qd_task *next;                                                                                                                                                                                 
  } qd_task_t;                                                                                                                                                                                          
                                                                                                                                                                                                        
  typedef struct qd_work_queue {                                                                                                                                                                        
  qd_task_t *head;                                                                                                                                                                                      
  qd_task_t *tail;                                                                                                                                                                                      
  pthread_mutex_t lock;                                                                                                                                                                                 
  _Atomic int count;                                                                                                                                                                                    
  } qd_work_queue_t;                                                                                                                                                                                    
                                                                                                                                                                                                        
  typedef struct qd_threadpool {                                                                                                                                                                        
  pthread_t *threads;                                                                                                                                                                                   
  int num_threads;                                                                                                                                                                                      
  qd_work_queue_t *queues;      // Per-thread queues                                                                                                                                                    
  qd_work_queue_t global_queue; // Overflow queue                                                                                                                                                       
  _Atomic int running;                                                                                                                                                                                  
  pthread_cond_t cond;                                                                                                                                                                                  
  pthread_mutex_t mutex;                                                                                                                                                                                
  } qd_threadpool_t;                                                                                                                                                                                    
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  **API:**                                                                                                                                                                                              
  ```c                                                                                                                                                                                                  
  qd_threadpool_t *qd_threadpool_create(int num_threads);                                                                                                                                               
  int qd_threadpool_submit(qd_threadpool_t *pool, void (*func)(void*), void *arg);                                                                                                                      
  int qd_threadpool_submit_priority(qd_threadpool_t *pool, void (*func)(void*), void *arg, int priority);                                                                                               
  void qd_threadpool_shutdown(qd_threadpool_t *pool, int wait);                                                                                                                                         
  void qd_threadpool_destroy(qd_threadpool_t *pool);                                                                                                                                                    
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  ### 3. Event Loop (qd_event)                                                                                                                                                                          
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - epoll-based for Linux efficiency                                                                                                                                                                    
  - Support for timers, signals, file descriptors                                                                                                                                                       
  - Multi-threaded event dispatch option                                                                                                                                                                
  - Async task integration                                                                                                                                                                              
                                                                                                                                                                                                        
  **Key Structures:**                                                                                                                                                                                   
  ```c

  ### 4. Timer Wheel (qd_timer)                                                                                                                                                                         
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - O(1) timer insertion and deletion                                                                                                                                                                   
  - Hierarchical wheel for wide time range                                                                                                                                                              
  - Integration with event loop                                                                                                                                                                         
                                                                                                                                                                                                        
  **Key Structures:**                                                                                                                                                                                   
  ```c                                                                                                                                                                                                  
  typedef struct qd_timer {                                                                                                                                                                             
  uint64_t expires;                                                                                                                                                                                     
  void (*callback)(void *arg);                                                                                                                                                                          
  void *arg;                                                                                                                                                                                            
  int slot;                                                                                                                                                                                             
  struct qd_list_head list;                                                                                                                                                                             
  } qd_timer_t;                                                                                                                                                                                         
                                                                                                                                                                                                        
  typedef struct qd_timer_wheel {                                                                                                                                                                       
  uint64_t current_tick;                                                                                                                                                                                
  uint64_t tick_interval_ms;                                                                                                                                                                            
  struct qd_list_head wheels[4][256];  // 4-level hierarchy                                                                                                                                             
  pthread_mutex_t lock;                                                                                                                                                                                 
  } qd_timer_wheel_t;                                                                                                                                                                                   
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  **API:**                                                                                                                                                                                              
  ```c                                                                                                                                                                                                  
  qd_timer_wheel_t *qd_timer_wheel_create(uint64_t tick_interval_ms);                                                                                                                                   
  qd_timer_t *qd_timer_add(qd_timer_wheel_t *wheel, uint64_t delay_ms, void (*cb)(void*), void *arg);                                                                                                   
  void qd_timer_cancel(qd_timer_wheel_t *wheel, qd_timer_t *timer);                                                                                                                                     
  int qd_timer_wheel_tick(qd_timer_wheel_t *wheel);                                                                                                                                                     
  ```                                                                                                                                                                                                   
                                                                                                                                                                                                        
  ### 5. Userspace IPC (qd_ipc)                                                                                                                                                                         
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - Unix domain sockets for reliability                                                                                                                                                                 
  - Message-based protocol with framing                                                                                                                                                                 
  - Service discovery and registration                                                                                                                                                                  
  - Optional shared memory for high throughput                                                                                                                                                          
                                                                                                                                                                                                        
  **Message Protocol:**                                                                                                                                                                                 
  ```c

  uint32_t version;                                                                                                                                                                                     
  uint32_t msg_type;                                                                                                                                                                                    
  uint32_t msg_id;                                                                                                                                                                                      
  uint32_t payload_len;                                                                                                                                                                                 
  uint32_t flags;                                                                                                                                                                                       
  uint64_t timestamp;                                                                                                                                                                                   
  } __attribute__((packed)) qd_ipc_header_t;                                                                                                                                                            
                                                                                                                                                                                                        
  typedef enum {                                                                                                                                                                                        
  QD_IPC_MSG_REGISTER = 1,                                                                                                                                                                              
  QD_IPC_MSG_UNREGISTER,                                                                                                                                                                                
  QD_IPC_MSG_DISCOVER,

  QD_IPC_MSG_RESPONSE,

Kernel IPC (qd_netlink)                                                                                                                                                                        
                                                                                                                                                                                                        
  **Design Goals:**                                                                                                                                                                                     
  - Generic Netlink for flexibility                                                                                                                                                                     
  - Async notification support

  - Fallback ioctl interface                                                                                                                                                                            
                                                                                                                                                                                                        
  **Key Structures:**                                                                                                                                                                                   
  ```c

  typedef struct qd_netlink_msg {
